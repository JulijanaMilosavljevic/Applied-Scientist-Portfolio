# Applied‑Scientist‑Portfolio

**Applied‑Scientist‑Portfolio** is a collection of machine‑learning and artificial‑intelligence projects demonstrating skills in data analytics, model development and the application of various algorithms. The repository contains multiple subprojects—from classification and regression to computer vision and recommendation systems. Each directory is a standalone project with its own README.

## Repository structure
Applied‑Scientist‑Portfolio/ <br/>
├── 01-tabular-churn/ – Telco churn prediction (logistic regression, Random Forest, XGBoost) <br/>
├── 02-house-regression/ – House price prediction using XGBoost, LightGBM and Random Forest with SHAP importance analysis <br/>
├── 03-cnn-rock-paper-scissors/ – CNN classifier for the Rock‑Paper‑Scissors game with image augmentation and Grad‑CAM visualizations <br/>
├── 04-cv-transfer-learning/ – Transfer learning on MobileNetV2 for flower classification <br/>
├── 05-bert-sentiment/ – Fine‑tuning a DistilBERT model for six‑emotion classification with CPU‑friendly training <br/>
├── 06-rag-search-assistant/ – RAG assistant with FLAN‑T5, Sentence Transformers and FAISS, interactive Gradio UI and evaluation tools <br/>
├── 07-fraud-detection-pipeline/ – Credit‑card fraud detection pipeline using logistic regression and imbalanced data with SHAP interpretability <br/>
├── 08-autoencoder-anomaly/ – Autoencoder‑based anomaly detector (notebook) <br/>
├── 09-movie-recommender/ – Movie recommendation system (notebook) <br/>
└── requirements.txt – List of Python dependencies <br/>


## How to use

1. **Clone the repository**  
   ```bash
   git clone https://github.com/JulijanaMilosavljevic/Applied-Scientist-Portfolio.git
   cd Applied-Scientist-Portfolio
   ```
2. **Set up a virtual environment and install dependencies**
   ``` bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Run a project
Each subproject has its own *README.md* with detailed instructions. Navigate into the desired directory and follow the steps to run the experiment or application.

## Purpose

This portfolio showcases data‑science knowledge and skills, focusing on algorithm application and results interpretation. It leverages popular open‑source tools such as scikit‑learn, PyTorch, Hugging Face, TensorFlow and FAISS. Each project explains its steps, evaluates models and offers suggestions for improvement.
